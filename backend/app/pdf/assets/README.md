# Packaged report font

`NotoSans.ttf` is the Noto Sans variable font, version 2.015, from the
[Google Fonts Noto Sans distribution](https://github.com/google/fonts/tree/main/ofl/notosans).
It includes the Vietnamese subset and is bundled so PDF generation needs no
font service or host font installation. The file's SHA-256 is
`bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.
